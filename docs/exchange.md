# 사이버머니 환전 요청

사용자로 로그인한 뒤 `POST /exchange`를 호출합니다.

```json
{
  "exchange_account": "환전받을 계좌",
  "exchange_price": 10000
}
```

사용자 ID는 토큰에서 확정합니다. `user_id`를 보내는 경우 본인 ID만 허용합니다.
환전액은 양의 정수이고 보유 잔액 이하여야 합니다.
사용자 행을 잠근 뒤 환전 기록 저장과 잔액 차감을 한 트랜잭션으로 처리합니다.
성공 응답은 201이며 환전 내역, 접수 메시지, 차감 후 잔액을 포함합니다.
실패 시 전체 롤백하며 잔액 부족은 409입니다.

- `GET /exchange`: 본인 환전 목록
- `GET /exchange/{exchange_seq}`: 본인 또는 관리자의 상세 조회
- `GET /exchange?user_id=사용자아이디`: 관리자의 특정 사용자 목록 조회

현재 은행 송금은 연동하지 않았습니다. 성공 응답은 송금 완료가 아니라 환전 요청 접수입니다.
충전과 동일하게 반복 요청은 별도 건으로 접수되고 잔액도 추가 차감됩니다.
실제 송금 연동 시 요청 식별자를 이용한 재시도 중복 방지와 처리 상태·실패 시 복원 절차를 추가해야 합니다.
