# 주문 등록과 조회

매니저는 본인이 작성하고 director가 승인한 품의로 주문을 등록합니다.
주문 API는 매니저 전용이며 director와 일반 사용자는 접근할 수 없습니다.

`POST /order`:

```json
{
  "proposal_proposal_no": "20261029000002",
  "order_price": 30000,
  "order_amount": 10,
  "product_company_product_company_code": "제조업체코드"
}
```

`order_price`는 요청한 총 주문금액이며 수량을 다시 곱하지 않습니다.
케이스는 품의에서 가져오고 번호와 날짜는 서버에서 생성합니다.
주문번호는 `proposal_no + 주문일자(YYYYMMDD)`이며 한국 날짜를 사용합니다.
예를 들어 `20261029000002` 품의를 2026-10-29에 주문하면 `2026102900000220261029`입니다.
동일 품의로 당일 중복 주문하면 409를 반환합니다.
합친 번호가 DB의 64자 제한을 초과하면 422를 반환합니다.

`GET /order?limit=20&offset=0`, `GET /order/{order_no}`에서
매니저는 담당 매니저와 관계없이 전체 주문을 조회할 수 있습니다.

기존 DB 구조를 그대로 사용하며 주문 등록 시 케이스 재고나 품의 상태는 변경하지 않습니다.
