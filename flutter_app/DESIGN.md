# POKEM 디자인 기준

포켓몬 로고를 떠올리는 노랑·파랑을 중심으로 밝은 카드 거래 앱을 구성합니다. 아래 값은 POKEM UI를 위해 선택한 팔레트이며, 공식 브랜드 규정의 색상값을 보증하는 문서는 아닙니다.

| 용도 | 색상 |
|---|---|
| 주요 버튼·제목·선택 아이콘 | `#2463AA` 파랑 |
| 배너·선택 강조 | `#FFCB05` 노랑 |
| 작은 보조 포인트 | `#E3350D` 빨강 |
| 기본 배경 | `#F7F9FC` |
| 본문 | `#1D2F4D` |
| 보조 문구 | `#69788E` |
| 경계선 | `#E2E8F1` |

- `lib/core/theme/app_theme.dart`에서 색상·글자 크기·입력창·버튼·카드·칩·탭·다이얼로그·알림 메시지의 공통 모양을 관리합니다. 고유 문구와 콘텐츠는 한국어를 유지하며 브랜드 표기는 POKEM, 머니 이름은 POKEM 머니로 통일합니다.
- `PokemWordmark`는 앱 헤더와 로그인 화면에서 공유합니다. 앱 패키지 ID·API 경로·DB 필드명은 변경하지 않습니다.
- 홈과 관심상품은 `ProductListingCard`를 공유합니다. 카드 사진은 전체가 보이도록 contain으로 표시하고, 제목·가격·상태·관심 버튼을 같은 배치로 유지합니다. 관심상품의 거래중·거래완료도 계속 표시합니다.
- 홈 상단을 압축해 첫 상품의 가격을 더 일찍 확인할 수 있게 했습니다. 필터·정렬·페이지 조회 및 기존 화면 이동은 유지합니다.
- 마이페이지는 프로필·잔액·처리 대기·거래 메뉴를 구분하며 판매/구매 스위치와 기존 메뉴 진입을 유지합니다.
- 채팅은 받은 메시지와 보낸 메시지의 배경·테두리·모서리를 구분하고 입력 영역을 흰색으로 분리합니다. 전송·WebSocket·읽음 정책은 변경하지 않습니다.
- 서버 응답 및 계정 찾기 이메일의 표시 문구도 POKEM으로 통일했습니다. 업무 상태·잔액·인증 방식은 변경하지 않습니다.

## 미리보기

아래 이미지는 실제 Flutter 화면을 **샘플 데이터**로 렌더링한 배치 미리보기입니다. 실제 DB 사용자·상품·잔액을 캡처한 것이 아니며, 상품 이미지가 없는 경우의 기본 표시를 포함합니다.

- [로그인](design/previews/login.png)
- [홈](design/previews/home.png)
- [마이페이지](design/previews/mypage.png)

외부 폰트나 이미지 패키지는 추가하지 않았습니다. 미리보기 생성에 사용한 로컬 한글 폰트는 앱에 포함하지 않으며, 실제 기기는 Roboto 및 시스템 한글 대체 글꼴로 표시합니다.
